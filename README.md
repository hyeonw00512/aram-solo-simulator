# 증바람 관전실 — 로컬 솔로 시뮬레이션

React + TypeScript + Vite로 만든 팬 제작 게임입니다. 로그인 없이 브라우저에서 AI 9명과 경기하고 상황별 전술을 선택합니다. Riot Games 공식 게임이 아니며 원작과 동일한 전투 수치를 보장하지 않습니다.

## 실행

```powershell
npm install
npm run dev
npm test
npm run build
npm run check:decisions
npm run simulate:1000 -- 10
```

1×/2×/4× 및 일시정지, 전술 카드 클릭/숫자키, 아이템 창 P/Esc를 지원합니다. 전술·증강 선택 중에는 시간이 멈춥니다. 아이템 상점을 열어 둔 동안에도 경기 시간이 멈춥니다.

## 전장과 승패

- 근접·원거리·공성 미니언이 주기적으로 생성되어 서로 싸우며 챔피언과 건물을 공격합니다.
- 외곽 포탑 → 안쪽 포탑 → 억제기 → 쌍둥이 포탑 → 넥서스 순서로 공성합니다. 선행 건물이 살아 있으면 후방 건물을 공격할 수 없습니다. 아군 미니언 없이 건물을 때리면 피해가 90% 감소합니다.
- 포탑은 미니언을 우선 공격하며, 포탑 근처에서 아군 챔피언을 때린 적에게 공격 대상을 바꿉니다. 억제기가 파괴되면 상대 팀 슈퍼 미니언이 나오고 180초 후 재생합니다.
- **넥서스 파괴로 승패를 결정합니다.** 기존 10분 점수 종료를 제거했습니다.
- 포탈은 살아 있는 외곽/안쪽 포탑으로 이동하며 둘 다 파괴되면 기지 앞에 도착합니다. 이동 2초, 재사용 15초입니다. AI는 부활 후 구매·탑승하고, 플레이어는 부활 후 구매/탑승/도보 복귀를 선택합니다.
- 관전 지도에 실제 미니언, 건물 체력·파괴 상태, 챔피언 위치·피해·회피를 표시합니다. 좌우 상태표에는 장비, 증강, 체력, 궁극기 상태와 신뢰를 표시합니다.

## 챔피언·빌드·효과

플레이 가능 풀은 아리, 애쉬, 블리츠크랭크, 다리우스, 이블린, 잔나, 카이사, 케넨, 레오나, 럭스, 말파이트, 모르가나, 나미, 소나, 베이가, 벡스, 야스오, 오른, 가렌, 아트록스 **20명**입니다. 양 팀 10명은 교체를 포함해 중복 없이 배정됩니다.

각 챔피언에 Q/W/E/R의 별도 계수, 마나 비용, 재사용 시간, 사거리, 주요 CC·회복·보호막·이동 효과가 있습니다. 물리/마법/고정 피해, 방어력/마저, 관통, 치명타, 공격 속도, 흡혈, 지속 피해, 치유 감소와 스킬 회피를 계산합니다.

실제 장비·능력치로 빌드를 판단합니다. AP 말파이트는 주문력 계수 궁극기 피해가 커지고 탱 말파이트는 체력·방어력과 방어력 계수 스킬이 강해집니다. AI의 전방 유지·견제·합류 판단에도 이 빌드를 사용합니다. AI 구매는 탱/AP/AD/지원 경로를 따라 필요한 재료를 조합합니다.

일반 맵 12 상점 **193종**을 열람할 수 있습니다. 검색, 분류, 가격, 하위 조합, 남은 비용, 6슬롯, 합성, 판매를 지원합니다. 사망/우물/출발 준비 중 구매합니다. 상점의 **‘이 게임의 효과’**에 지원 효과를 표시해 원본 설명과 구분합니다.

구현된 효과에는 주문 검, 리안드리 화상, 내셔 온힛, 강철심장 성장, 체력→공격력/주문력 전환, 마나 충전·전환, 보호막, 존야 자동 경직, 향로/흐르는 물/월석의 아군 보조, 치유 감소 등이 있습니다. 사용 장비는 조건에 맞춰 자동 발동하고 물약·영약은 상점에서 직접 사용합니다. 미지원 시야/계약 등의 아이템에는 구매 불가 이유를 표시합니다. 나머지 별도 고유 효과가 구현되지 않은 항목은 기본 능력치만 적용한다고 표시합니다.

선택 증강은 **72종(등급별 24종)**입니다. 1·7·11·15레벨 기준 총 4회이며, 첫 선택 이후에는 해당 레벨에 도달한 뒤 사망해야 선택할 수 있습니다. 회차별 등급은 독립적으로 무작위 결정되어 같은 등급이 4번 나올 수도 있습니다. 같은 선택창의 카드와 새로고침은 같은 등급을 유지하고, 각 카드마다 1회 새로고침할 수 있습니다. 한 번 제시된 증강은 해당 경기에서 다시 제시하지 않습니다.

## 선택과 AI 기억

9가지 상황에 서로 다른 메뉴를 제공합니다. 진입/후퇴/교환/관망/엄호/포탑 수비/체력팩에 라인 정리/건물 압박/재정비를 추가했습니다. 미니언 없이 적 포탑에 접근했을 때, 공성 웨이브가 도착했을 때, 궁극기가 준비되지 않았을 때 메뉴가 달라집니다.

AI는 성향, 체력, 인원, 거리, 스킬·마나, 빌드, 웨이브와 이전 신뢰를 함께 판단합니다. 매 단계 다시 판단하므로 이탈, 늦은 호응, 추격과 교환 신호 오해가 발생합니다. 정해진 결말을 무작위로 출력하지 않고 행동·이동·피해 결과로 복기를 만듭니다.

모든 플레이어가 같은 팀 4명에 대한 관계를 저장합니다. 반복된 무리와 단순한 패배를 구분하며 실제 엄호는 신뢰 회복으로 이어집니다. 불신하더라도 현재 각이 좋거나 수비가 불가피하면 호응할 수 있습니다. 최근 6개 교전의 판단 이유를 펼쳐 볼 수 있습니다.

## 데이터와 구현 한계

Data Dragon 한국어 **16.21.1**의 기본/성장 능력치와 아이템 가격·조합·능력치를 사용합니다. 원본 173명 중 위 15명만 플레이합니다. 아이템 404종, 수집 증강 115종 아이콘을 로컬에 보관하지만 **아이콘 수가 구현된 효과 수를 뜻하지 않습니다.** 증강 선택 풀은 12종입니다.

스킬 수치·발동·거리·성장·웨이브 시간은 독립 설계입니다. 1초 단위·1차원 전투를 대각선 SVG에 투영합니다. 실제 투사체 경로, 충돌, 수풀 은신·시야, 소환사 주문, 모든 원작 스킬 재시전/진화·조건을 재현하지 않습니다. 공포/에어본/매혹 등 일부 행동 불가는 기절로 단순화하고 야스오 바람 장막은 일시 보호 효과로 표현합니다. 애쉬 E는 시야 지형이 없는 현재 모델에서 원작 정찰을 재현하지 않습니다. 레벨은 시간에 따라 오르며 미니언 경험치·막타 경제도 원작과 다릅니다. 밸런스 검증이 끝난 완제품은 아닙니다.

## 저장과 코드

저장 키는 `chaos-brawl-game-v3`를 유지합니다. 예전 v3 저장은 건물·전투 상태와 일회성 증강 보상을 초기화해 이어갑니다. 이미 적용한 보상은 중복 지급하지 않습니다. v1/v2 저장을 삭제하지 않습니다. 새 경기 버튼은 확인 후 현재 진행을 교체합니다. 같은 저장 상태와 선택은 같은 결과를 냅니다.

- `src/engine/world.ts`: 미니언·공성·건물·넥서스 승패.
- `src/engine/kits.ts`, `combat-v4.ts`: 개별 스킬·상태 이상·피해·아이템 발동.
- `src/engine/stats.ts`, `augments.ts`, `item-effects.ts`: 능력치 전환·증강·효과 설명.
- `src/engine/encounter.ts`, `memory.ts`: 선택·독립 판단·신뢰·복기.
- `src/engine/items.ts`, `shop.ts`: 카탈로그·조합·구매·AI 구매.
- `src/ui/WorldLayer.tsx`, `BuildDetails.tsx`: 공성 상태·빌드/스킬 상세.

## 검증

자동 검사는 신뢰 누적/회복, 불신 상태의 호응, 중복 없는 배정, 메뉴 유효성, 포탈, 조합/슬롯/골드, 피해/저항/회피, AP·탱 빌드 차이, CC·마나·재사용, 지원 효과 시너지, 지속 피해, 증강 중복 지급 방지, 미니언·건물·넥서스, 저장 후 재현성과 전체 경기 종료를 검사합니다.

`check:decisions`는 아군 1명이 사망한 동일한 1,000개 출발 상태에서 진입/후퇴/교환을 각각 실행해 3,000개 교전을 기록합니다. `reports/decision-coverage.json`에 결과와 재현 시드가 있습니다. `simulate:1000 -- N`은 N판을 끝까지 진행합니다. 이 결과는 통합 진행·경우의수 검사이며 원작 승률이나 확정 밸런스가 아닙니다.


## 칼바람 나락 배치 (2026-10-27)

16.21 Map12 원본 지형의 양 팀 외곽/안쪽/쌍둥이 포탑, 억제기, 넥서스, 부활 및 미니언 생성 좌표를 `data/howling-abyss-layout.json`에 추출했습니다. 모든 건물에 동일한 회전·축척을 적용해 원본 지면에서의 거리 비율을 보존합니다. 건물 아이콘 크기와 이름표 위치는 가독성을 위해 별도 조정하며 전투 거리는 여전히 1차원 시뮬레이션입니다.

포탈은 넥서스 뒤 → 외곽 포탑 앞이며, 외곽 파괴 후 두 번째 포탑 앞으로 이동합니다. 두 번째 포탑이 파괴되어도 출구를 유지합니다. 공개 지형 파일에서 포탈 자체의 좌표는 확인되지 않아 입구/출구 오프셋은 추정입니다. 포탈 위치까지 원작과 완전히 동일하다는 의미는 아닙니다. 적 기지 포탈 사용은 미구현입니다.

기존 저장의 건물 위치는 자동 갱신하며 체력, 파괴 상태, 타깃, 웨이브와 재생 시각은 보존합니다. 추출 재실행: `node scripts/extract-map-layout.mjs` (원본 `data/raw/map12-geometry.json` 필요).

- 원본 지형: https://raw.communitydragon.org/16.21/game/data/maps/mapgeometry/map12/base.materials.bin.json
- 포탈 연결 규칙: https://www.leagueoflegends.com/en-us/news/game-updates/aram-2023-preview/


## 온라인 배포

상점 목록·추천·조합 재료·상위 아이템은 한 번 클릭해 상세를 보고 더블클릭해 구매할 수 있습니다. 목표 아이템의 골드가 부족하면 보유 재료를 제외한 조합 트리에서 구매 가능한 상위 재료부터 선택하고, 남은 골드·슬롯으로 추가 재료를 구매합니다. 예를 들어 1200G로 루덴의 메아리를 구매하면 사라진 양피지를 구매합니다. 구매 전 재료 목록과 실제 지출을 표시하며, 아이템을 자동 판매하거나 같은 목표에 불필요한 재료를 추가하지 않습니다. 오른의 현장 제작은 한 번에 재료 하나만 기존 3초 제작 규칙으로 처리합니다.

전장 위 빠른 지시에서 합류·후퇴·이니시·라인 정리·수비·집중 공격을 팀 전체 또는 특정 아군에게 보낼 수 있습니다. 집중 공격은 지도/적군 목록에서 선택한 보이는 적을 우선 공격하며, 일반 전투와 분기 교전 모두에 적용됩니다. 각 팀원은 성향·신뢰·체력·인원에 따라 수락/미수락/참여 어려움을 따로 기록합니다. 채팅과 같은 3초 간격, 최대 24초 적용이며 사망·은신으로 대상을 놓친 집중 공격 지시는 종료됩니다. 내 분기 선택을 덮어쓰지 않고, 추가 AI 답장을 강제하지 않습니다. 기존 미아핑 3회/10초 제한도 유지합니다.

팀원의 기억은 선택 전 신뢰 요약, 교전 반응의 ‘기억한 경험’, 종료 후 신뢰 변화, 챔피언 상세의 최근 교전 기록으로 확인합니다. 반응에는 판단 당시의 신뢰·기억과 실제 상위 판단 요인을 저장하므로 이후 신뢰가 변해도 과거 설명이 바뀌지 않습니다. 불신에 따른 주저와 유리한 각/불가피한 수비에 따른 호응을 구분하고, AI 팀원끼리의 신뢰 변화도 남깁니다. 기존 채팅 빈도와 미아핑 제한은 유지하며, 새 기록이 없는 이전 저장에는 과거 변화를 추정해 만들지 않습니다.

전장 바로 아래의 내 챔피언 HUD에서 체력·보호막·마나/기력/기류·경험치, Q/W/E/R 랭크와 실제 남은 재사용 시간, 자원 부족·행동 불가 상태, 보유 아이템·증강과 현재 행동을 확인할 수 있습니다. 사망/포탈/기지 상태와 직접 선택한 교전 행동이 평소 성향 설명보다 우선합니다. 최근 받은 피해·회복·회피와 저체력/주변 인원 열세도 표시합니다. HUD의 상점 및 스킬·성향 버튼은 기존 팝업을 열며, 스킬은 전투 조건에 맞춰 자동 시전됩니다.

전술 선택 창에는 현재 주변 인원·저체력 아군·적 지원 간격·궁극기 준비 상태를 요약한 지도가 표시됩니다. 창을 내려도 전장에 위험/기회 표시가 남습니다. 선택 후 전장 바로 아래에서 내 행동 → 팀원 반응 → 상대 대응 → 실제 결과를 읽을 수 있으며, 각 판단의 이유·진입 신호 오해·뒤늦은 합류를 표시합니다. 점선은 실제 교전 단계에서 이동한 좌표 기록입니다. 설명을 위해 전투 순서나 결과를 변경하지 않으며, 과거 저장에 이동 기록이 없으면 이동선만 생략합니다. 결과는 게임 시간 8초 동안 표시되고 상세 기록은 교전 복기에 남습니다.
